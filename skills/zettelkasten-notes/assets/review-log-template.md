# 体检日志模板（review log template）

> 用途：把每次体检、导入、系统改动按时间追加到库内日志文件，只追加、不改旧行。
> 统一前缀 `## [YYYY-MM-DD] 类型 |`，便于用 `grep "^## \[" 日志文件 | tail -5` 查看最近记录。

## 条目格式

```markdown
## [2026-11-07] lint | 每周体检（15 分钟）
- 新增卡数：6（reviewed）｜草稿：4
- 平均每卡连接数：2.3（上周 2.1）
- 孤岛卡：3 / 120（2.5%）
- 超期草稿（>30 天）：2
- 产出调用：本周被 1 篇文章引用 5 张
- 已处理：孤岛 2 张补连接；超期草稿 1 张合并到旧卡
- 未处理（下周继续）：断链 1 条

## [2026-11-07] import | <来源简称>
- 新增草稿 5，合并到旧卡 2，退回（无来源）1

## [2026-11-07] change | 试行：案例卡标题必须含情境
- 预期：检索案例更快
- 观察期：至 2026-12-05

## [2026-12-05] decision | 案例卡标题含情境 → 保留（指标同等，检索更快）
```

## 类型约定

| 类型 | 何时写 |
|---|---|
| `lint` | 每次体检（脚本或人工） |
| `import` | 每批外部导入或 AI 抽取 |
| `change` | 开始一项系统规则实验 |
| `decision` | 实验结束：保留或撤回，附理由 |
| `fileback` | 项目/问答结束后回填候选卡 |
