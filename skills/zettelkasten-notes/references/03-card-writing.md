# 03 写卡层：工具选择、文献笔记、永久笔记标准（教程第 17–24 篇）

> 来源：《卡片盒笔记法》48 篇教程第 17–24 篇。
> 本文件是「怎么写一张卡」的操作规范：工具判据、重述 vs 摘抄、文献→永久三步跃迁、永久卡写作标准。


## 第17篇：工具选择指南——纸笔、数字工具还是两者兼备？

### 核心论点

工具只应服务于三个动作：**写卡片、建立连接、让知识生长**。选择标准不是功能多少，而是它是否让你更专注于思考。若精力都耗在插件、模板、数据库或工作流上，工具再强也不合格。作者最推荐“分工式混合方案”：**纸笔负责深度，数字负责效率。**

### 操作要点（含判断标准）

- **选纸笔**：适合喜欢手写与物理触感、每天能固定坐在书桌前、不以速度为首要目标、愿意体验卢曼原版方法的人。手写较慢，不能复制粘贴，会迫使人删掉废话；卡片还能摊开、移动，以空间关系激发连接。
- **纸笔代价**：检索依赖编码和索引；卡片盒不便携；修改只能涂改或重写；大量卡片占空间。
- **选数字**：适合需要秒级检索、经常移动捕捉、喜欢双链或图谱、愿意学习工具且能克制折腾冲动的人。
- **数字代价**：功能和插件容易分心；打字、复制粘贴太快，容易把思考退化为摘抄；屏幕缺少同时铺开几十张卡片的空间感。
- **具体分工**：闪念笔记用手机备忘录、Flomo或微信文件传输助手；文献笔记按习惯用数字或纸笔；永久笔记用纸笔，或在数字工具中“一个字一个字敲出来”以保持手写感；索引、搜索和连接交给数字工具。
- **混合工作流**：手机捕捉 → 每天固定时间用电脑或纸笔处理 → 在数字工具中搜索并建立双链 → 定期用桌面铺卡或图谱/随机漫游回顾。

### 可执行 checklist

- [ ] 先确认自己更需要“深度”还是“效率”。
- [ ] 只选能支持写、连、生长的最小工具集。
- [ ] 为捕捉、加工、连接、漫游分别指定工具。
- [ ] 连续使用一周后再调整，不先搭“完美系统”。

## 第18篇：纸笔派实操——A6卡片、木质卡片盒与编码系统

### 核心论点

纸笔系统的关键不在昂贵器材，而在三个约束：**卡片大小迫使一张只写一个想法；每张卡片有唯一编号；归档位置由连接决定而非分类决定。**

### 操作要点（含原文示例）

- **规格**：A6约为 **148mm×105mm**，比明信片略小、比名片大，可写约100—200字。名片太小，无法展开；A5/A4太大，容易塞进多个想法。纸张宜稍厚、光滑但不反光、钢笔书写不洇墨；选空白或横线，不建议方格。
- **卡片盒**：卢曼式木盒前面开口，卡片竖排，可放几百张；优点是边缘可见、抽取方便、有仪式感，代价是占地、不便携、好盒子价格可达几百元。鞋盒、文件盒、纸盒都可替代，唯一关键是“能竖放、便翻阅”；鞋盒需书立或隔板防倒。先买100张卡和1个盒子，写一个月再扩充。
- **编码**：编号是“位置”，不是分类。首卡为`1`；与1相关的下一张为`1/1`；其后为`1/1/1`；与1相关但与1/1无关可为`1/2`；插入1/1和1/2之间用`1/1a`，再细插可用`1/1a1`。初学者推荐“卢曼简化版”：基础号1、2、3……，相关卡在原号后加`/1`、`/2`。时间戳如`202610031200`简单唯一但无邻近关系；`A1、A2……`可扩展但也不支持插入。唯一性是硬标准，因为“参见卡片B”必须精确指向。
- **字段模板**：左上角编号；右上角来源（可选）；正文写一个脱离上下文仍可理解的完整想法；底部写连接。

原文示例：

> 1/3a 来源：《刻意练习》第78页 即时反馈是刻意练习区别于普通重复的关键因素。普通的重复练习， 做完之后往往要等很长时间才能得到反馈。但刻意练习要求反馈尽 可能即时，因为即时反馈能让你在每一次练习中立即调整，而不是 等到错误已经固化成习惯之后才纠正。 参见：1/2（舒适区）、2/1（反馈循环）、4/3（技能习得）

- **归档**：无关则放末尾并给新基础号；与某卡相关则放其后并给子编号；与多卡相关时，放到“最相关”卡后，在其他卡上用铅笔写“参见新编号”。连接可写“参见3/1”“反驳2/5”“补充4/2”“例子见7/3”。正面写满就换卡，不写背面。

### 可执行 checklist

- [ ] 准备A6卡、好写的笔和可竖放卡片的盒子。
- [ ] 选定唯一编号规则，并理解编号表示位置而非主题。
- [ ] 每卡只写一个完整想法，写满即另起一张。
- [ ] 归档时选择最相关邻居，并补上双向“参见”。

## 第19篇：数字派入门——Flomo、Obsidian、Logseq如何选？

### 核心论点

三者不是同类工具：**Flomo负责“记”，Obsidian负责“连”，Logseq负责“拆”。** 不应横向比功能，而应按工作环节与个人习惯选择。作者首推 **Flomo + Obsidian**。

### 操作要点

- **Flomo：捕捉工具**。打开即写，三秒完成；用标签替代文件夹；手机、电脑、网页同步。适合灵感多但写作需求少、厌恶设置、先培养记录习惯的人。代价是无标题、不能合并笔记或批量改标签，双链和图谱弱，回顾筛选粒度有限。
- **Obsidian：构建工具**。双向链接、图谱视图、1000+社区插件，本地Markdown文件可长期掌控。适合有长期知识网络目标、愿意维护系统、需跨领域联想并把卡片转化为文章或书的人。代价是自由度带来高维护成本，手机端偏重，最容易陷入插件与模板折腾。
- **Logseq：大纲型工具**。每一行都是可单独引用、链接、嵌入的“块”；默认从每日笔记开始，适合先流水记录后整理。适合喜欢“大纲+双链”、习惯每日记录、重视开源免费和数据掌控的技术用户。代价是必须适应`- `大纲格式，复杂排版弱，移动端成熟度较低。
- **组合方案**：Flomo在手机和碎片场景捕捉；每隔几天或一周导出/同步到Obsidian（文中举例插件为“Flomo Sync”或“SyncToFlomo”）；在Obsidian中重写成文献/永久笔记、建立双链并看图谱。两者各司其职：不在Flomo里纠结整理，也不在Obsidian里强求快速捕捉。

### 可执行 checklist

- [ ] 只想快速开始就用Flomo记3条闪念。
- [ ] 有构建目标就用Obsidian建库、写1卡、连1条双链。
- [ ] 偏爱每日大纲就用Logseq写当天第一个块。
- [ ] 采用组合时固定每几天或每周做一次“导入—加工—连接”。

## 第20篇：阅读一本书，如何开始写第一张文献笔记

### 核心论点

划线只是标记，不是笔记；真正的文献笔记发生在“读”和“记”之间。它不是全书摘要，而是对少量真正有启发内容的主动加工。

### 操作要点（读前—读中—读后）

- **读前**：纸笔派把A6卡和笔夹在书里；数字派打开Flomo、Obsidian等并建“读书笔记-书名”临时文件夹。捕捉入口必须三秒内可用。
- **读中三动作**：①遇到真正有启发的段落先停下，问“这段话说的是什么？用我自己的话怎么说？”一本书可能只有10%值得处理；②合上书或页面再写，避免只换词。写不出就重读后再合上；仍写不出则标记并跳过；③标注书名+页码或章节，如`《刻意练习》p.78`。
- **字段与篇幅**：来源；100—300字核心内容；自己的联想、连接或疑问。太短可能没抓住核心，太长通常仍在“翻译”而非“转译”。

原文示例：

> 来源：《刻意练习》p.78 核心：刻意练习不是重复已经会的东西。它要求挑战刚好超出当前能力 的任务，并且必须有即时反馈，让你能在每次练习后马上调整。任务不 能太难，也不能太简单。 思考：这和我之前理解的“一万小时定律”不一样。一万小时只是时间 量，但刻意练习强调的是“质量”——有没有挑战、有没有反馈、有没 有调整。时间只是必要条件，不是充分条件。

- **读后**：电子书划线须集中处理。读完一章后逐条判断是否值得写卡；100条划线可能只有10条转为文献笔记，其余留在书里。一本300页的书只产出5张真正理解、有触动的笔记，也胜过100条未消化摘抄。

### 可执行 checklist

- [ ] 捕捉工具能在三秒内进入书写状态。
- [ ] 遇到启发段落先停下，而不是顺手划线后继续读。
- [ ] 合上原文，以完整句子重述一个核心意思。
- [ ] 补齐来源与“我的思考”，读后只处理高价值划线。

## 第21篇：摘抄不是文献笔记，重述才是

### 核心论点

改写只是同义词替换、语序调整和删减修饰语；重述则是**抛开原文语言结构，用自己的思维框架重新编码意义**。摘抄无效的机制是：大脑未参与意义重构，只保留作者的逻辑与措辞，因而几个月后产生“好像懂了”的熟悉感，却无法复述、调用或写作。

### 操作要点（含坏例→好例原文）

- **操作**：合上原文，等五分钟，让工作记忆清空表面措辞，再凭理解写。把原文与笔记并排比较；若结构、句式、用词仍相似，就是改写。合格标准是：“让原文作者认不出这是自己的话——但又不得不承认你说得对。”
- **关键词坑**：关键词只是索引，离开当时语境便失效。原文对照：
  - 坏例：“即时反馈很重要”
  - 好例：“即时反馈是刻意练习区别于普通重复的关键因素，因为它缩短了‘尝试—调整’的循环周期”
- **摘要坑**：摘要企图覆盖整章，是压缩信息；文献笔记只取“对我最有启发的一个点”，是提炼理解。
- **无来源坑**：无法追溯、引用、验证。最低格式为书名+页码，或文章标题+作者+链接。
- **无思考坑**：仅完成转译，没有与已有知识连接。末尾必须回答：这让我想到什么？与我已知的什么有关？产生了什么疑问？
- **句式改造练习原文**：“如果原文是‘因为A，所以B’，你就写成‘B的发生，根源在于A’。如果原文是‘首先……其次……最后……’，你就写成‘这三个因素中，最关键的是……’。”

### 可执行 checklist

- [ ] 合上原文并等待五分钟后再写。
- [ ] 与原文对照结构、句式和用词，明显相似就重写。
- [ ] 使用完整句子，只保留一个核心想法。
- [ ] 补齐可追溯来源及自己的联想、疑问或连接。

## 第22篇：从文献笔记到永久笔记——三步内化跃迁

### 核心论点

文献笔记写“作者说了什么、我理解了什么”，永久笔记写“我产生了什么想法”。跃迁前先验收成熟度：能不看原文说清核心；已有联想/疑问/连接；已发现它与既有知识的关系。只做到第一点的仍是半成品。

### 操作要点（每步动作与产出）

1. **提炼**：问“这条文献笔记里，最让我有感触的是什么？”不概括整条，只抓一个“啊哈点”。**产出：一个永久笔记种子**，如“一万小时定律是错的”。
2. **独立**：合上文献笔记，只凭记忆与理解另写新卡。正文不能出现“作者认为”“书中说”“原文提到”，不能依赖“上文”，必须用完整句子陈述一个完整观点。**产出：标题+自足正文的永久卡**。
3. **连接**：写完后搜索关键词，问它与哪张旧卡有关，至少建立一个支持、反驳、补充、延伸或举例关系。**产出：进入知识网络的节点**，末尾有“参见”或双向链接。

原文永久笔记示例：

> **标题：** 一万小时定律的问题：把“时间”当成了“进步”的充分条件
>
> **正文：** 一万小时定律的核心假设是：只要在某个领域投入足够的时间，就能成为专家。但这个假设是错的。时间只是必要条件，不是充分条件。真正决定进步的，是练习的“质量”——你有没有挑战刚好超出当前能力的任务？有没有获得即时反馈？有没有在每次练习后做出调整？没有这些，一万小时只是重复，不是进步。
>
> **连接：**
> - 相关卡片：[[即时反馈是刻意练习区别于普通重复的关键因素]]
> - 相关卡片：[[舒适区与学习区]]
> - 来源：文献笔记 [[刻意练习-第78页]]

不是每条文献笔记都要升级；没有真正触动或无法进入知识网络的原料可停止加工。

### 可执行 checklist

- [ ] 先过“理解、思考、关联”三项成熟度检查。
- [ ] 只提炼一个最有触动的种子。
- [ ] 合上旧笔记另写，不沿用来源依赖句式。
- [ ] 至少建立一个明确关系，并保留文献笔记来源。

## 第23篇：永久笔记的写作标准——脱离上下文仍可独立理解

### 核心论点

永久笔记必须“自给自足”：即使忘记写作缘由、来源和相邻卡片，只读本卡仍能完全理解。独立指**理解上的独立**，不是连接上的孤立。

### 操作要点（含坏例→好例原文）

- **三年后测试**：想象三年后第一次看到它。若“不太确定”“好像懂又好像不懂”或必须翻别卡，均不合格。
- **四个不能出现及原文对照**：
  1. 指示代词。错误：“这个观点很好” → 正确：“即时反馈是刻意练习区别于普通重复的关键因素——这个观点很好”
  2. 依赖来源。错误：“作者认为反馈的频率比质量更重要” → 正确：“反馈的频率比反馈的质量更重要。来源：文献笔记[[刻意练习-第78页]]”
  3. 指代上下文。错误：“正如上文所说，反馈太慢会导致调整来不及” → 正确：“如果反馈太慢——比如一个月后才收到老师的批改——你在等待期间会反复重复错误的动作”
  4. 模糊判断。错误：“即时反馈很重要” → 正确：“即时反馈的价值在于：它让‘尝试—调整’的循环周期尽可能短，让错误在成为习惯之前就被纠正”
- **字段模板**：①标题——用一句话概括核心想法，让人浏览时即知观点；②正文——以自己的完整句子解释、论证或举例；③连接——注明支持/反驳/补充/延伸；④来源——可选，置于末尾，不进入正文逻辑。
- **标题写法**：标题应直接陈述主张，宜像“反馈的频率比反馈的质量更重要”，不宜写“关于反馈的笔记”“读书感想”等主题标签。
- **篇幅**：本篇没有规定固定字数，标准是“足以完整展开一个想法且不塞入第二个想法”。纸卡实操给出的容量参照是A6约100—200字；若写不下，应拆成相互连接的多卡，而非写背面或合并观点。
- **常见不合格**：出现“这个/它/上文”；以“作者认为”代替直接陈述；只有“很重要/有启发”等评价；只有标题或关键词而无论证；需依赖来源或其他卡才能懂；一张卡同时容纳多个观点。

原文整组对照中的坏例：

> 这个观点很有意思。作者认为反馈很重要，但我觉得不止是反馈本身，反馈的频率也很关键。就像上文说的，如果反馈太慢，调整就来不及了。

对应好例的核心正文：

> 很多人讨论反馈时，关注的是“反馈是否准确”“反馈是否有建设性”。但在技能习得中，更关键的因素是反馈的“频率”。如果反馈太慢——比如一个月后才收到老师的批改——你在等待期间会反复重复错误的动作，错误会固化成习惯。等反馈来了，你不仅要学正确的动作，还要先改掉错误的习惯。即时反馈的价值在于：它让“尝试—调整”的循环周期尽可能短，让错误在成为习惯之前就被纠正。

### 可执行 checklist

- [ ] 遮住来源与相邻卡，只读正文做“三年后测试”。
- [ ] 搜索并替换指示代词、来源句式、上下文指代和模糊评价。
- [ ] 标题直接表达主张，正文完整展开且只含一个想法。
- [ ] 来源移到末尾，同时保留至少一个明确连接。

## 第24篇：实战练习——读完立刻写下三张卡片

### 核心论点

三张是最小完整练习：一张太少，未必走完流程；十张太多，容易疲劳应付。三张依次体验从输入到输出：**文献笔记 → 永久笔记 → 连接笔记**。

### 操作要点（可直接复用）

1. **文献笔记**：从最近读过的书、文章或公众号中选一个“啊哈段落” → 合上原文 → 用自己的完整句子重述一个核心想法 → 标书名+页码或文章标题+作者+链接 → 写联想、关系或疑问 → 问“三个月后还能懂吗？”

   原文模板：
   > 来源：《XXX》p.XX 核心：［用自己的话，写出核心意思］ 思考：［这条笔记让我想到了什么］

2. **永久笔记**：从第一张找最有感触的一个种子 → 合上文献笔记 → 以完整句子写成独立观点 → 检查“这个/那个”“作者认为/书中说”“上文/如前所述”“很重要/很有启发”四类词 → 做“三年后测试”。

   原文模板：
   > 标题：［一句话概括核心想法］ 正文：［用完整的句子，展开这个想法。不依赖任何上下文。］ 连接： - 相关卡片：［和哪张卡片有关］ - 来源：文献笔记［第一张卡片的标题或编号］

3. **连接笔记**：搜索已有卡片、旧笔记或收藏 → 判断两卡是支持、反驳、补充、延伸还是举例 → 用一句话解释为什么有关 → 在两张卡末尾互相加“参见”。连接笔记不是新笔记类型，只是对关系的显式说明。

   原文模板：
   > 连接笔记： 卡片［A］和卡片［B］的关系：［支持/反驳/补充/延伸/举例］ 具体说明：［一句话说明为什么它们有关］

原文永久卡实战例：

> 标题：写作是一种发现，不是一种表达 正文：我们通常认为，写作是把脑子里已经想清楚的东西“写出来”。 但更准确的说法是：写作本身就是想清楚的过程。你动笔之前以为你 知道要说什么，但写着写着，你会发现你原本不知道的东西。写作不 是思考的“输出”，而是思考的“发生”。 连接： - 相关卡片：［写作是线性的吗］ - 来源：文献笔记［为什么写作这么难］

### 可执行 checklist

- [ ] 连续完成三张，不先读更多教程或追求完美。
- [ ] 第一张完成“来源—重述—我的思考”。
- [ ] 第二张完成“种子—独立正文—三年后测试”。
- [ ] 第三张写明关系，并在两端建立双向“参见”。

## 写一张合格永久卡的检验清单

- [ ] 一张卡只表达一个核心想法，而不是章节摘要或观点合集。
- [ ] 标题是一句明确主张，浏览标题即可判断卡片在说什么。
- [ ] 正文使用完整句子，而不是几个关键词或提纲。
- [ ] 内容完全用自己的话重述，不保留原文的结构、句式和措辞。
- [ ] 遮住来源后，正文仍不依赖原书、原文或作者才能成立。
- [ ] 不含“这个、那个、这些、那些、它、此”等不明指示代词。
- [ ] 不含“作者认为、书中说、原文提到、正如XX所说”等来源依赖句式。
- [ ] 不含“上文、下文、前面提到、如前所述”等序列指代。
- [ ] 不以“很重要、很有启发、很有道理、有点意思”等模糊评价代替论证。
- [ ] 对关键概念说明对象、条件、因果或例子，读者不必猜“为什么”。
- [ ] 能通过“三年后测试”：忘记写作情境后只读本卡仍完全理解。
- [ ] 篇幅足以完整展开一个想法；超出一张A6卡约100—200字的容量时优先拆卡。
- [ ] 来源若保留，放在末尾，不成为正文理解的必要前提。
- [ ] 至少连接一张已有卡，并注明支持、反驳、补充、延伸或举例关系。
- [ ] 新旧两卡互相可达，纸卡写双向“参见”，数字卡建双向链接。
