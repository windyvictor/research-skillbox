# zettelkasten-notes（卡片盒笔记法）

## 核心思想

卡片盒不是仓库，是**生产线**。闭环只有三个字：**写**（用自己的话，写成独立可复用的卡片）→ **连**（新旧卡片连接，知识成网络）→ **长**（主题卡片足够多、连接足够密时，文章自然"长"出来）。

卢曼的账：约 9 万张卡片、58 本专著 + 数百篇论文、30 年、每天约 6 张、成本为零。产出不靠意志力硬撑，靠系统把大任务拆成每天可完成的小任务。

三条不可协商的铁律（违反任意一条，系统失效）：
1. **用自己的话复述，不摘抄。** 摘抄是去语境化的信息搬运；复述是强制理解，且让内容可被未来的自己检索调用。
2. **一卡一想法。** 卡片必须"独立可理解"——遮住来源和相邻卡片，三年后重读仍然懂。这是独立理解，不是连接孤立。
3. **每张新卡都写进已有网络的语境里。** 先找相关旧卡，再决定新卡怎么写、连到哪。不预设主题文件夹：按主题分类必然遭遇"往哪放"的两难，连接比分类重要。

## 日常节奏（默认参数，可直接套用）

- **每天 3–6 张卡**（起步 3 张，目标是卢曼的 6 张），只考核连续性，不考核数量
- **每张新卡至少建立 1 条连接**，并写明关系（支持/反驳/补充/延伸）
- **闪念笔记 1–2 天内处理完**，处理完即弃；收件箱必须清空
- **标签**：单卡 1–3 个；主题标签 ≤20、状态 ≤5、并行项目 ≤3、全局 ≤30
- **审视**：每周 15 分钟（清空收件箱、补漏连、翻旧卡）、每月 1 小时（查卡片质量、清理标签、更新索引）、每季半天（修剪、重组、发现新主题）
- **立题门槛**：某主题 >20 张卡且连接成网 → 可写成文章

## 关键判据速查

| 判断 | 标准 |
|---|---|
| 这张永久卡合格吗 | 遮住来源和邻卡做"三年后测试"；不得出现指示代词、"作者认为"、"正如上文"、模糊评价（"很重要/有意思"）；标题直接陈述主张 |
| 该建索引了吗 | 该主题 >10 张卡；索引 = 主题词 + 3–5 张核心卡 + 关系标注，不是目录 |
| 可以开始写了吗 | 三信号全绿：≥10–20 张卡 + 彼此有论证关系 + 有想说的冲动 |
| 这个连接值得连吗 | 三判据：关系明确、产生新意、可被调用；拒绝为连而连的"图谱幻觉" |
| 该读什么书 | 由输出决定：当前卡片的缺口指向什么，就去读什么 |

## 完成前自检

- [ ] 卡片是用户自己的话复述，没有大段摘抄
- [ ] 一卡一想法；通过"三年后测试"（遮住来源仍可读懂）
- [ ] 每张新卡至少 1 条到既有卡片的显式连接，且注明关系类型
- [ ] 没有为新卡预设主题文件夹；用编码地址 + 标签 + 链接组织
- [ ] 闪念笔记有明确处理时限，收件箱清空
- [ ] 有审视节奏（周/月/季）与每日卡片数下限
- [ ] 当前有输出目标在驱动采集（输出决定输入），不是为收藏而记
