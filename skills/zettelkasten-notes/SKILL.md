# zettelkasten-notes（卡片盒笔记法）

## 核心思想

卡片盒不是仓库，是**生产线**。闭环只有三个字：**写**（用自己的话，写成独立可复用的卡片）→ **连**（新旧卡片连接，知识成网络）→ **长**（主题卡片足够多、连接足够密时，文章自然"长"出来）。

卢曼的账：约 9 万张卡片、30 年、每天约 6 张、成本为零；产出常被引为 58 本著作 + 数百篇文章（阿伦斯书中数字，其他来源统计口径不一，引用时注明）。产出不靠意志力硬撑，靠系统把大任务拆成每天可完成的小任务。

三条不可协商的铁律（违反任意一条，系统失效）：
1. **用自己的话复述，不摘抄。** 摘抄是去语境化的信息搬运；复述是强制理解，且让内容可被未来的自己检索调用。AI 参与时同样适用：不外包理解。
2. **一卡一想法。** 卡片必须"独立可理解"——遮住来源和相邻卡片，三年后重读仍然懂。这是独立理解，不是连接孤立。
3. **每张新卡都写进已有网络的语境里。** 先找相关旧卡，再决定新卡怎么写、连到哪。不预设主题文件夹：连接比分类重要。

## 先读本地规则

若卡片库根目录有规则文件（如 AGENTS.md、CLAUDE.md、README 中的约定），其目录结构、命名、字段与权限**优先于**本技能的默认值。没有时用默认边界：

- **可以**：新建草稿卡（status: draft）、给出连接建议、生成体检报告、在日志末尾追加记录
- **不可以**（须人确认）：改动原始材料、删除卡片、把草稿升为 reviewed/evergreen、批量重命名或移动

需要为一个新库起草规则文件时，用 `assets/vault-rules-template.md`。

## AI 参与时的规则（任何学科、任何工具通用）

- **分工**：AI 做抽取候选、查重、找旧卡、建议连接、体检；人做"是否成卡、标题主张、连接是否成立、是否升级状态"。
- **AI 产出一律草稿**：`author: ai`、`status: draft`；人审过才可改为 reviewed/evergreen，AI 不得自行升级。
- **来源锚定**：AI 卡必须在 `sources` 指向文献卡或原件路径；原件只读，不得凭空生成主张。
- **复述不豁免**：AI 草稿只是改写候选；人至少重写标题与一句正文，才算自己的卡。
- **非对称核查**：人不必复核全部输出，只抽查三处——主张是否忠于来源、连接方向是否成立、是否与旧卡重复。
- **外部导入**：任何外部来源（其他技能/工具的导出、AI 对话摘录、剪藏）只进收件箱、一律 draft、必须带 sources。
- 大批量 AI 产出可先进"AI 收件箱/沙盒"，人筛选后再移入主卡片盒。细则见 `references/10-ai-collaboration.md`。

## 日常节奏（默认参数，可直接套用）

- **每天 3–6 张卡**（起步 3 张，目标是卢曼的 6 张），只考核连续性，不考核数量；AI 草稿不计入
- **每张新卡至少建立 1 条连接**，并写明关系（支持/反驳/补充/延伸/修正）
- **闪念笔记 1–2 天内处理完**，处理完即弃；收件箱必须清空
- **标签**：单卡 1–3 个；主题标签 ≤20、状态 ≤5、并行项目 ≤3、全局 ≤30
- **审视**：每周 15 分钟（清空收件箱、补漏连、翻旧卡）、每月 1 小时（查卡片质量、清理标签、更新索引）、每季半天（修剪、重组、发现新主题）；每次固定时长、只出报告、把指标记进日志（见 09）
- **立题门槛**：某主题 ≥10–20 张卡且彼此有论证关系（经验值，不是硬线；>20 张可写长文或系列）

## 关键判据速查

| 判断 | 标准 |
|---|---|
| 这张永久卡合格吗 | 遮住来源和邻卡做"三年后测试"；不得出现指示代词、"作者认为"、"正如上文"、模糊评价（"很重要/有意思"）；标题直接陈述主张 |
| 卡片成熟度 | `status`: draft（草稿/AI 候选）→ reviewed（人已审）→ evergreen（多次使用、反复修订仍成立）；被推翻用 superseded + `superseded_by`。状态是给人看的成熟度信号，不是任务清单 |
| 新旧卡冲突怎么办 | 不改写旧卡原主张；写修正卡并用"反驳/修正"连到旧卡；措辞或笔误才直接改旧卡 |
| 该建索引了吗 | 该主题 >10 张卡；索引 = 主题词 + 3–5 张核心卡 + 关系标注，不是目录 |
| 可以开始写了吗 | 三信号全绿：≥10–20 张卡 + 彼此有论证关系 + 有想说的冲动 |
| 这个连接值得连吗 | 三判据：关系明确、产生新意、可被调用；拒绝为连而连的"图谱幻觉" |
| 该读什么书 | 由输出决定：当前卡片的缺口指向什么，就去读什么 |

## 常见坑（Gotchas）

- 把摘抄"换几个词"冒充复述——这是 AI 最常犯的错；改写必须换结构、带上自己的判断。
- 按主题建文件夹，或用 PARA 文件夹装卡片本身；PARA 只适用于项目和资源层。
- 为凑连接而连接，或把链接数、图谱好看程度当质量指标。
- 把 AI 草稿、外部导入的候选卡计入每日卡片数，或让它们未经人审就变成 reviewed。
- 擅自翻译用户的卡：卡片用什么语言写，就用什么语言写和检查（`check_card.py --lang auto`）。
- 静默覆盖旧卡的主张，抹掉思想演化的轨迹。
- 体检时直接动手改卡、删卡——体检只出报告，改动须人确认。
- 引用卢曼数据（卡片数、著作数、每日张数）不注明口径。

## 完成前自检

- [ ] 卡片是用户自己的话复述，没有大段摘抄
- [ ] 一卡一想法；通过"三年后测试"（遮住来源仍可读懂）
- [ ] 每张新卡至少 1 条到既有卡片的显式连接，且注明关系类型
- [ ] 没有为新卡预设主题文件夹；用编码地址 + 标签 + 链接组织
- [ ] AI 生成或外部导入的卡：status 为 draft、author 正确、sources 非空
- [ ] 跑过 `scripts/check_card.py`，无 ERROR
- [ ] 闪念笔记有明确处理时限，收件箱清空
- [ ] 当前有输出目标在驱动采集（输出决定输入），不是为收藏而记
