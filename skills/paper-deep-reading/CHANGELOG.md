# CHANGELOG · paper-deep-reading

相对 **2026-10-22** 正本的主要变更（用户可读要点）。版本日期：2026-11-01（Asia/Shanghai）。

1. **新增 Step −1 阅读目的（四选一）**：领域入门 / 找 idea / 写 Related Work / 复现基线；目的锁定默认深度与报告侧重，并写入报告头。
2. **L3 新增「思路重建」专节**：失败模式 → 关键观察 → 核心直觉；明示为 🔎 推断，不得写成作者心理。
3. **全程强制证据四级标签** 📄📚🔎❓；文献卡结论栏只收 📄/📚。
4. **检验协议可执行化**：Steelman → 最脆弱假设（四向）→ 反例四步 → 一周最小验证 → 锁死效应 → 诚实注脚。
5. **第二遍强制 Claim–Evidence–Warrant 矩阵**；理论文改为 Claim–Theorem–Assumption。
6. **合书复述关 + 读后六件套**：L3 必做；L2 至少前三项；跳过复述须注明。
7. **贡献层采用李沐公式**：新意×有效×问题大小（1/10/100）；L1 即做价值粗分。
8. **L1 固定 A/B/C 分流**：服务批量筛选；C 类升档精读。
9. **新增「领域地图」模式**：2A/2B/2C、派别表、演进 Mermaid、精读候选与深读配额提示。
10. **新增 Step 5 卡片盒导出**：文献卡五栏、对比卡/问题卡草稿、想法卡仅候选且须用户批准；对接用户卡片盒/知识库（如 zettelkasten 类）；遵守 raw/ 只读（若规范要求）。
11. ~~优化/动力系统/NDO 专用分维表~~：**已移除**（2026-11-01 晚间按用户反馈：不为小方向单开特例；通用理工科清单 + 分维度质疑足够）。
12. **升级 AI 核验协议**：存在性 → 原文 → Full/Partial/No support → 未读不引（Oxford + faithfulness 粒度）。
13. **嵌入 Pineau 可复现快检**与消融–基线–算力三连问；吸收 NeurIPS/ICLR 评审精神（按贡献类型解读）。
14. **PLOS 六问**可作为 L1 报告骨架；难文可选 **QEC 预处理**；Nielsen **深读配额**写入精力原则。
15. **可选开关**：第一遍后暂停（批量用）；组会讲解版；可借鉴写作/图表栏。
16. **反模式清单写入红线**：含 Strawman、流利感错觉、海量浅扫、只看仿真曲线等。
17. **与后续检索衔接**：报告末输出下一步检索关键词；候选 idea / 新问题交用户审。
18. **README 来源表大幅增补**；Nature Cornwell 2026 仅记「策略先行（全文未核）」，不编造七步。
19. **交互教程提示词**增加批判嵌入句与不得编造数值约束。
20. **保留**三遍法、取全文路由、时空坐标、认知阶梯、载体阶梯、苏格拉底辩证、GB/T 7714 等原有核心能力。
